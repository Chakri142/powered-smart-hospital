# Powered Smart Hospital (PSH) - 3D Asset Registry & Licensing

All 3D assets in this project are 100% original, procedurally generated in JavaScript using parametric algorithms derived from OpenSCAD source definitions (`openscad/hospital_assets.scad`).

## Assets Inventory

1. **`scad_v1_medical_cross`**: Parametric 3D Medical Cross Emblem (`THREE.BoxGeometry` + `THREE.MeshPhongMaterial`).
2. **`webgl_v1_token_ring`**: Outer Glowing Queue Node Ring (`THREE.TorusGeometry` + `THREE.MeshBasicMaterial`).
3. **`webgl_v1_particle_field`**: Procedural Ambient Depth Particles (`THREE.SphereGeometry`).
